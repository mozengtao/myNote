# 通用地基：搜索空间、单调性、剪枝

后续五章都复用这里的四个词。

不要把双指针理解成「两个下标一起走」。
那是实现，不是原理。

双指针成立，是因为下面这条因果链成立：

```
暴力在枚举一个二维状态空间
        |
        v
这个空间里存在单调方向
        |
        v
沿单调方向移动一个指针
        |
        v
可以永久丢掉一整块状态
        |
        v
两个指针各自最多走一遍
        |
        v
O(n^2) 变成 O(n)
```

---

## 1. 真正被搜索的是什么

大多数「看起来像一维数组」的问题，暴力其实在搜一对下标。

```
给定数组 a[0..n-1]

真正的候选不是单个元素，而是一对位置:

    (i, j)

含义随问题变化:

    两个数的和:          i < j, 检查 a[i] + a[j]
    一段子数组:          i <= j, 检查 a[i..j]
    两个序列的对齐:      i 在 A 上, j 在 B 上
    读和写两个角色:      i 读, j 写
    链上两个位置:        slow 和 fast
```

所以搜索空间天然是二维的。

```
              j -->
        0   1   2   3   4
      +---+---+---+---+---+
    0 |   | * | * | * | * |
      +---+---+---+---+---+
    1 |   |   | * | * | * |
i     +---+---+---+---+---+
    2 |   |   |   | * | * |
      +---+---+---+---+---+
    3 |   |   |   |   | * |
      +---+---+---+---+---+
    4 |   |   |   |   |   |
      +---+---+---+---+---+

* = 暴力需要检查的状态
空格 = 非法或不考虑 (例如 i >= j)
```

格子数大约是 `n(n-1)/2`，所以暴力是 O(n^2)。

这就是第一性原理的起点：

> 双指针优化的不是「循环写法」，而是「二维格子里哪些格子根本不必看」。

---

## 2. 暴力为什么必须扫完全部格子

如果状态之间没有关系，每一个 `(i, j)` 都可能独立地成为答案。

没有关系意味着：

- 知道 `(i, j)` 不行，推不出邻居也不行
- 知道 `(i, j)` 更好，推不出另一边可以丢掉

这时必须枚举。双重循环是诚实的。

只有当空间里出现**单调性**，才能少看格子。

---

## 3. 单调性到底是什么

单调性不是「数组看起来比较整齐」。

单调性是一句可以证明的话：

> 从当前状态出发，沿某一个轴继续走，目标量只朝一个方向变化。
> 因此，这一侧的一整块区域可以被一次性判死刑，或者一次性判安全。

五种双指针，单调对象不同：

```
+------------------+-------------------------------------------+
| 类型             | 真正单调的东西                               |
+------------------+-------------------------------------------+
| 左右夹逼         | 有序数组上的和 / 宽度变小后的容量上界           |
| 滑动窗口         | 窗口扩大后约束更紧，缩小后约束更松              |
| 快慢指针         | 相对距离随时间单调增加，或环上相位差            |
| 双序列扫描       | 两个递增序列上「当前最小值」只增不减             |
| 读写指针         | 已处理前缀的正确性已经冻结                     |
+------------------+-------------------------------------------+
```

关键句：

> 单调的不是指针本身，而是「指针移动后，被丢掉的那些状态」。

---

## 4. 一次移动 = 剪掉一块矩形

这是整本教程最重要的几何图。

假设当前停在 `(i, j)`，并且证明：

「所有 `j' < j` 且左端仍是 i 的状态都不必再看。」

那么一次 `j--` 不是丢掉 1 个格子，而是丢掉一整列（或一整行、或一个矩形）。

```
              j -->
        0   1   2   3   4
      +---+---+---+---+---+
    0 |   | x | x | x | . |
      +---+---+---+---+---+
    1 |   |   | x | x | . |     x = 已被剪掉
i     +---+---+---+---+---+     . = 还可能看
    2 |   |   |   | * | . |     * = 当前状态
      +---+---+---+---+---+
    3 |   |   |   |   | . |
      +---+---+---+---+---+
    4 |   |   |   |   |   |
      +---+---+---+---+---+

当前在 (2, 3)
若证明「j=3 这一侧对所有更左的 i 都更差」，
则整列或整块 x 永久消失。
```

如果每次移动都能剪掉 Theta(n) 个格子，
而移动次数只有 O(n)，
那么被检查的格子从 O(n^2) 降到 O(n)。

---

## 5. 为什么指针以后不用回来

「不回头」不是风格，是正确性条件。

必须证明下面的不变量：

```
指针已经跨过的区域 R

对任意未来状态 S:

    R 中没有任何格子还能成为更优答案
    或者 R 中的信息已经被压缩进当前窗口/当前前缀
```

如果这个命题不成立，指针就必须允许回退，那就不是双指针，而是普通搜索或栈。

反向移动通常会破坏不变量：

```
正确方向: 丢掉已被证明无用的一侧
反方向:   把已经判死刑的状态重新放回搜索空间
          同时又可能跨过尚未检查的存活状态
          既可能漏解，也可能死循环
```

## 6. 为什么总移动次数不超过 2n

两个指针各自有自己的轨道，轨道长度最多是 n。

```
left  从 0 走到 n-1，只增不减，最多 n 步
right 从 0 走到 n-1，或从 n-1 走到 0，单向，最多 n 步

每一步循环至少推动其中一个指针
循环次数 <= left步数 + right步数 <= 2n
```

这就是 O(n) 的来源。

不是「感觉扫了一遍」，而是：

> 二维空间被一条单调路径穿过；路径上每个节点剪掉一大块；路径长度是线性的。

```
O(n^2) 个格子
        |
        |  单调性把格子分成
        |  「当前这条前沿」+「已死区域」
        v
前沿上只有 O(n) 个点需要计算
        |
        v
每个点 O(1) 更新
        |
        v
       O(n)
```

如果某次移动不能剪掉一块区域，只是换一个格子看看，复杂度不会下降。

## 7. 五类双指针是五种剪枝几何

```
左右夹逼          滑动窗口           快慢指针

从两端往中间      右端扩张、左端收缩   同一条链上两速度

+-----------+     +-----------+      +-----------+
| * * * * * |     | . . . . . |      | s ->      |
|   * * * * |     | . # # # . |      |    f ->   |
|     * * * |     | . # # # . |      | 相对距离  |
|       * * |     | . . . . . |      | 单调增大  |
|         * |     +-----------+      +-----------+
+-----------+     窗口是一段连续区间
对角线以上的对
被从外往里吃掉


双序列扫描        读写指针

两个数组两个轴    读指针扫全集
                  写指针冻结已完成前缀

  B -->             0 1 2 3 4
+---------+         r ------->
| * . . . |         w -->
| * * . . |         [0, w) 已经是最终答案
| * * * . |
+---------+
A
每次推进更小的一侧
```

几何不同，逻辑相同：

> 当前决策能证明一整块区域永久无用。

## 8. 判断题该不该用双指针

先画搜索空间，再问四个问题。

```
Q1  暴力枚举的是 (i, j) 吗？
    否 -> 先别想双指针

Q2  固定一个轴，另一个轴上的目标量是否单调？
    否 -> 双指针会漏解

Q3  移动之后，丢掉的区域以后还可能复活吗？
    会复活 -> 必须回退，不是双指针

Q4  两个指针是否各自最多走 n 步？
    否 -> 复杂度未必降到 O(n)
```

四个 YES，才写两个下标。

## 9. 本教程故意不讲的东西

不讲：

- 「这题是双指针模板」
- 「先背左右再背窗口」
- 「看到有序就夹逼」这种口号

要讲：

- 空间里哪一块死了
- 死掉的原因是哪一条单调性
- 为什么反方向移动会让死人复活，或者让活人被埋

从下一章开始，每一类都把这条链走一遍，再用五道题把链钉进直觉。
