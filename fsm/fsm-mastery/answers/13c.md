# 第 13c 课参考答案

先自己做 `lessons/13-hsm/13c-internal-external/quiz.md`，再对答案。

## 1. `PLAYING` 上 `VOLUME` 若走 `fsm_transition(self)`，轨迹多出哪两行？

会多出 **`exit PLAYING: stop rendering`** 和 **`entry PLAYING: start rendering`**。用户看见画面闪一下、解码器重启，其实只想调音量。

## 2. 「下一状态仍是 PLAYING」为何不能判断内部转移？

自环 **外部** 转移下一状态也是自己，但会退出再进入。内部：不退出、不重进，只跑动作。差在 **Kind**，不在下一状态是否相同。

## 3. 为何 `DATA_STARVE` 必须外部，`VOLUME` 必须内部？

`DATA_STARVE` 要离开 `PLAYING`：必须 `exit PLAYING` 停渲染，再进 `BUFFERING`。`VOLUME` 人还在 `PLAYING`，若走外部会误停再开渲染。

## 4. `STOP` 为何不能做成 `PLAYING` 上的内部转移？

内部不退出叶子、也不退出 `ACTIVE`，渲染器和活动资源关不掉。`exit ACTIVE` 只在 **外部** 转移、且 LCA 在盒子之外时才会发生。

## 5. 第 12 课 `CONNECTED` 上的 `DATA_OK` 自环，有进入 / 退出之后应标哪种？

应标 **内部**（保活，不要重启「已连接」资源）。若标成外部自环，可能毁掉链路/密钥/省电相关的进入副作用（先退出再进入 `CONNECTED`）。
