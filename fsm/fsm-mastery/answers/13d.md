# 第 13d 课参考答案

先自己做 `lessons/13-hsm/13d-history/quiz.md`，再对答案。

## 1. 在 `PLAYING.SEEKING` 时 `STOP`，再 `PLAY`

| 模式 | 进入的叶子 |
|------|------------|
| 无历史 | `CONNECTING`（`ACTIVE` 的默认子状态） |
| 浅历史 H | `PLAYING` 的默认子状态 **`NORMAL`** |
| 深历史 H* | **`SEEKING`** |

浅历史不得读 `playing_hist`：那一层记得 `SEEKING`，一读就变成深历史。浅只读 `active_hist`（直接孩子 `PLAYING`），再进该孩子的默认。

## 2. `ACTIVE` 的默认子状态是什么？何时用到？

**`CONNECTING`**。在 **无历史** 模式，或历史槽为空 / 第一次进入时使用。浅/深在槽有效时覆盖默认。

## 3. 历史和 13c 内部转移差在哪？音量为什么不是历史？

内部转移：人 **还在框里**，只改当前数据。历史：人 **已经离开过**，回来时选哪个叶子。音量是框内数据调整，不是「上次停在哪」。

## 4. 从 `BUFFERING` 停止再播放，浅/深为何可落到同一叶子？能证明深历史写对了吗？

`BUFFERING` 没有更里层。浅、深都只恢复 `ACTIVE` 的直接孩子 `BUFFERING`，`playing_hist` 用不上。**不能** 证明深历史写对了；要靠 `SEEKING` 那条轨迹区分 H 与 H*。

## 5. 为何不要发明 `STOPPED_FROM_SEEKING` 代替历史槽？

那是把「上次在哪」乘进扁平枚举：停止变成许多终点，播放要从每个终点各画一支箭。13a 的爆炸换了一种写法回来。历史槽按层记忆，停止仍是一个 `STOPPED`。
