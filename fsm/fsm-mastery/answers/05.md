# 第 05 课参考答案

先自己做 `lessons/05-traffic-light/quiz.md`，再对答案。

## 1. 下一状态 vs 动作；只改 `state` 会怎样？

下一状态回答「去哪」。动作回答「走的时候对外做什么」。只改 `fsm->state`、不调用动作：软件以为已换色，路口灯没亮（软件绿、硬件红）。

## 2. 初始化打印 `RED on` 算什么？

是 **动作**（副作用），不是状态、事件或监护。上电必须点灯，发生在 `fsm_init`，可以没有 `TICK`。

## 3. 为何仍叫 `TICK` 而不是超时？

`TICK` 只是节拍事件，每次到来都是「又来了一个输入」。超时是第 06 课：预约了剩余拍数、减到 0 再变成到期事件。`Fsm` 里可以放整数 `ticks` 当数据，用监护 `ticks == N` 决定是否换色——那仍是数据 + 监护，不是定时器对象。

## 4. 在 `action_green_on()` 里写 `fsm->state = STATE_GREEN`

破坏 **分发**：动作不该改状态。先动作再由分发写入下一状态；若动作自己改状态，监护以后无处安放，两条进入同一状态、动作不同的转移也会立刻错。
