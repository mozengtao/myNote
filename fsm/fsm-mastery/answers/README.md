## 怎么用

1. 读完该课 `LESSON.md` 和代码轨迹
2. 合上讲义，答 `quiz.md`
3. 打开本目录对应文件，只对你不确定的题
4. 图题以讲义的框和箭头为准；答案里的 Mermaid / ASCII 是同一张图的简写
