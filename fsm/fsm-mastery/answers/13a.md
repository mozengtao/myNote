# 第 13a 课参考答案

先自己做 `lessons/13-hsm/13a-composite/quiz.md`，再对答案。

## 1. 三个活动状态各画一支 `STOP` vs 画在 `ACTIVE` 上

**用户看见的行为相同**：活动中按停止都回到 `STOPPED`。**实现差在**：扁平要按叶子复制箭头；复合只在父框上画一次。扁平爆炸从 `PlayingSeeking`、`ConnectingRetry1` 这类 **特征相乘的名字** 开始：每加一个特征，公共退出再乘一倍。

## 2. `ACTIVE` 为何不是 `Fsm.state` 的可停靠取值？

`ACTIVE` 是盒子，进入时必须落到一个叶子。任意时刻恰好一个当前状态，有盒子之后指的是 **叶子**（父框表示「也处于这个更大的局面」）。

## 3. 扁平 FSM、HSM、Statechart、Actor 各解决什么？为何本课只实现复合却先划界？

| | 解决什么 |
|--|----------|
| 扁平 FSM | 「现在是什么」有名字；特征一乘就贵 |
| HSM | 一张图里公共转移按叶子复制（状态爆炸） |
| Statechart | HSM 再加历史、正交、伪状态等图上零件 |
| Actor | 许多对象同时活着、不能直接改对方字段（第 14 课） |

后面子课只会往 HSM 上加零件。先划界，避免把历史/`H`、正交第二列、邮箱并发提前塞进本课。

## 4. `in_active(state)` vs `bool in_active` 字段

谓词由叶子枚举推出来，不会和 `state` 打架。独立布尔是第二个「当前局面」，容易出现 `state==STOPPED` 且 `in_active==true`。

## 5. 第 12 课为何不准省电与 `CONNECTED` 并列？盒子怎么说？

并列会看起来「不在已连接」。省电应和 **已连接（醒着）** 放进同一个盒子，**共享离开该盒子的那条退出**（断开会话 / 回扫描），而不是再拉一条顶层出路。
