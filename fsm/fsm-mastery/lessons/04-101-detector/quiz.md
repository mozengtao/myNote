# 第 04 课测验

先自己写答案，再看 `answers/04.md`。

1. 什么是守卫？它和事件有什么不同？为什么「位等于 1」写在箭头上，而不是再做一个叫 `S0_expect1` 的状态？
2. 若没有守卫、把每一位都复制进状态名，四个前缀大约会变成多少个框？问题出在哪？
3. 已经处于 `S101` 时到来 `BIT1`，下一状态是什么？为什么不是继续留在 `S101`？请用「当前后缀」解释重叠。
4. PIN 锁里事件都叫 `UNLOCK`，却可能走到 `UNLOCKED` 或留在 `LOCKED`。分开写出事件和守卫。
5. 序列 `10101` 会命中几次 `101`？从 `S0` 逐步写出每一比特后的状态。
