# 11. 递进练习

## Why

看懂教程和自己独立解决问题是两件不同的事。下面的练习按 4 个 Level 递进，只给"目标 / 输入数据 / 需要回答的问题 / 建议图形 / 需要计算的统计量"，**不给代码答案**——请你对照前面的心智模型和示例自己写代码验证。

建议每完成一题后，用 [08_failure_and_debug.md](08_failure_and_debug.md) 的排查表检查一下自己的图有没有踩坑。

---

## Level 1：基础图形

### 练习 1.1 —— Line Plot

- **目标**：巩固"时间序列 -> line"的映射，以及 `ax.plot()` 的基本参数。
- **输入数据**：自己生成 60 天的模拟"每日活跃用户数"（可以用 `np.random.normal` + 一个缓慢上升的趋势项）。
- **需要回答的问题**：用户数整体是在增长还是下降？有没有周期性（比如周末更高）？
- **建议图形**：`ax.plot()`，考虑加 `marker`。
- **需要计算的统计量**：整体均值、最大值出现在第几天。

### 练习 1.2 —— Bar Chart

- **目标**：巩固"类别比较 -> bar"，以及 y 轴 baseline 的重要性。
- **输入数据**：5 个不同地区的月度销售额（自己编几个数值，故意让差距不大，比如 980/1020/1050/990/1010）。
- **需要回答的问题**：哪个地区销售额最高？差距有多大（绝对值和百分比）？
- **建议图形**：`ax.bar()`，画两版：y 轴从 0 开始 vs 从接近最小值开始，对比视觉差异。
- **需要计算的统计量**：最大值与最小值的差、差值占最小值的百分比。

### 练习 1.3 —— Histogram

- **目标**：巩固"分布 -> histogram"以及 bins 的影响。
- **输入数据**：用 `np.random.exponential` 生成 1000 个"任务处理时间"样本（这种分布右侧有长尾，和正态分布形状不同）。
- **需要回答的问题**：这批处理时间的分布形状是什么样（是否对称）？大多数任务需要多长时间？
- **建议图形**：`ax.hist()`，尝试 `bins=10/30/80` 三种设置。
- **需要计算的统计量**：mean、median（对比两者谁更大，思考为什么）。

## Level 2：组合与关系

### 练习 2.1 —— Scatter

- **目标**：巩固"两变量关系 -> scatter"，以及"相关不等于因果"的边界意识。
- **输入数据**：自己构造"广告投放金额"和"当日销售额"两列数据，让它们有正相关但加入较大噪声。
- **需要回答的问题**：投放金额和销售额是否相关？相关强度如何？能不能得出"投放导致了销售额增长"的结论？
- **建议图形**：`ax.scatter()`。
- **需要计算的统计量**：`np.corrcoef()` 相关系数。

### 练习 2.2 —— Boxplot

- **目标**：巩固"多组分布比较 -> boxplot"。
- **输入数据**：4 个班级的考试成绩（每班 30 个学生，均值/标准差各不相同）。
- **需要回答的问题**：哪个班级平均分最高？哪个班级成绩最分散？有没有班级存在明显的异常分数？
- **建议图形**：`ax.boxplot()`。
- **需要计算的统计量**：每班的 median、IQR。

### 练习 2.3 —— Multiple Subplots

- **目标**：巩固 `plt.subplots(nrows, ncols)` 和多指标对齐观察。
- **输入数据**：模拟一台服务器 24 小时的 CPU 使用率、内存使用率、磁盘 IO 三个指标（可以人为在某个时间段让三者同时升高，模拟一次真实负载高峰）。
- **需要回答的问题**：三个指标是否在同一时间点出现异常？异常持续了多久？
- **建议图形**：`plt.subplots(3, 1, sharex=True)`。
- **需要计算的统计量**：每个指标的均值和峰值出现的时间点。

## Level 3：统计驱动的工程分析

### 练习 3.1 —— P95/P99 可视化

- **目标**：巩固"统计量 -> 可视化标记"的心智模型，理解为什么工程上重视尾部延迟。
- **输入数据**：1000 个 API 响应时间样本，构造成"大部分很快，少数很慢"的长尾分布（可以用两个不同参数的正态分布叠加，参考 [stats_markers/distribution_stats_overlay.py](../stats_markers/distribution_stats_overlay.py) 的思路）。
- **需要回答的问题**：多数用户的体验如何（P50）？最差 5%/1% 用户的体验有多差（P95/P99）？如果只报告 mean，会掩盖什么信息？
- **建议图形**：`ax.hist()` + `ax.axvline()` 叠加 P50/P95/P99。
- **需要计算的统计量**：mean、median、P50、P95、P99。

### 练习 3.2 —— Error Rate Dashboard

- **目标**：综合运用多子图 + 双 Y 轴（谨慎使用）+ 统计标记。
- **输入数据**：模拟 7 天的"每小时请求量"和"每小时错误率"，制造 1-2 次错误率突增的事件。
- **需要回答的问题**：错误率突增是否和某个流量特征（比如流量突增或突降）相关？突增事件持续了多久？
- **建议图形**：先尝试两个独立子图（诚实版本），再尝试双 Y 轴版本，对比哪种更容易正确解读，思考 [07_misleading_charts.md](07_misleading_charts.md) 提到的风险。
- **需要计算的统计量**：整体 error rate、异常时段的 error rate、异常检测阈值（比如 mean + 3*std）。

### 练习 3.3 —— 日志分析（进阶）

- **目标**：独立完成一次"从日志到 PNG 报告"的完整流程，不看 [workflows/log_analysis/](../workflows/log_analysis/) 的代码。
- **输入数据**：自己设计一份日志格式（可以参考 `service=xxx latency=xxx status=xxx` 的思路，但换成不同的字段，比如加入 `region=` 字段）并生成模拟数据。
- **需要回答的问题**：不同 region 的延迟是否有差异？错误率随时间如何变化？P95 延迟是否达标（自己设定一个 SLA 阈值，比如 200ms）？
- **建议图形**：时序图 + boxplot（按 region 分组）+ 直方图（叠加 P95）。
- **需要计算的统计量**：分组 groupby 统计、P50/P95/P99、SLA 达标率（`(latency <= 200).mean()`）。

## Level 4：综合工程案例

### 练习 4.1 —— 网络性能 Dashboard

- **目标**：不看 [workflows/network_analysis/](../workflows/network_analysis/) 的代码，独立完成一份网络性能分析报告。
- **输入数据**：自己生成一份 `timestamp, throughput_mbps, rtt_ms, loss_percent` 格式的 CSV，制造 2-3 段"网络异常"时间窗口（吞吐骤降、RTT 骤升、丢包升高应同时发生）。
- **需要回答的问题**：
  1. 整体网络质量如何（throughput 的分布、RTT 的 P50/P95/P99）？
  2. 异常事件发生在什么时候？能否用统计规则（比如丢包率超过 mean+3std）自动检测出来？
  3. throughput 和 RTT 是否相关？这种相关性在"正常时段"和"异常时段"是否表现不同？（提示：分别画正常点和异常点，用不同颜色区分，参考 [pitfalls/pitfall04_correlation_not_causation.py](../pitfalls/pitfall04_correlation_not_causation.py) 的"共同原因"思路——异常事件很可能是同时压低吞吐、拉高延迟和丢包的共同原因）
- **建议图形**：3 个时序图（标出异常点）+ 1 个散点图（区分正常/异常两种颜色）+ 1 个分布图（叠加百分位数）。
- **需要计算的统计量**：P50/P95/P99、异常检测阈值、正常时段 vs 全部数据的相关系数对比。

### 练习 4.2（可选，挑战题）—— 从零设计一份 Dashboard

- **目标**：给定一个你自己工作/生活中真实关心的问题（比如"我每天的睡眠时长和运动量有没有关系"、"某个产品各功能模块的使用频率"），完整走一遍：
  ```text
  我要回答什么问题 -> 数据是什么结构 -> 应该计算什么统计量
  -> 应该用什么图形表达 -> 如何验证图形没有误导我 -> 如何从图中得到结论
  ```
- **输入数据**：自己收集或模拟。
- **需要回答的问题**：由你自己定义。
- **建议图形**：由你自己根据 [03_chart_selection.md](03_chart_selection.md) 的决策树决定。
- **需要计算的统计量**：由你自己根据问题决定。
- **验收标准**：能不能对着你产出的图，用一段完整的话向别人解释"这张图在回答什么问题，结论是什么，以及你怎么确认这个结论没有被图形误导"。
